# System Design Questions and Answers 🚀

### 1. What is system designing?
```js
System design is the process of designing elements of a system such as architecture, modules and components,
the different interfaces of those components and the data that goes through that system.

// Types of system design HLD and LLD
1. HLD (High Level Design) => Describe the main components that would be developed for the resulting product.
The system architecture details, database design, services and processes, the relationship between various modules,
and features.

2. LLD (Low Level Design) => Describe the design of each element mentioned in the High Level Design of the system. 
Classes, interfaces, relationships between different classes, and actual logic of the various components.
```
